# Mistakes in Challenge 4 (Student Grade Analyzer)

### 1. Incorrect max() usage
- `max(avg_scores)` returns the **key with the highest alphabetical order**, not the student with the highest average.
- Example: it would print “Charlie” even if his score wasn’t the highest.
- Correct usage:
  ```python
  top_student = max(avg_scores, key=avg_scores.get)
